# Still Lost in Definitions: How ‘Resilience’ Is Used in Ecology

This repository contains the data and code associated with the manuscript:

**Lin, H., Krishna Moorthy, S. M., Hector, A., & Salguero-Gómez, R.**
*Still Lost in Definitions: How ‘Resilience’ Is Used in Ecology.*

## Overview

This study synthesises 594 ecological publications published between 1977 and 2025 to examine how resilience is defined and quantified across ecological subfields. We evaluate patterns in resilience metric use, identify common dimensions of resilience quantification, and assess whether study attributes predict metric selection.

## Repository Structure

```text
data/            Raw and processed datasets
code/         R scripts and Python scripts used
figures/         Main manuscript figures included

```

## Reproducibility

All statistical analyses were conducted in R. Scripts are provided to reproduce data processing, analyses, and figures presented in the manuscript.
